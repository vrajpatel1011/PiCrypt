# PiCrypt
PiCrypt is a lightweight, web-based application that enables users to hide one image inside another using steganographic techniques. Designed with simplicity and privacy in mind, PiCrypt provides an intuitive GUI for securely embedding secret images within cover images — all from your browser.


# Execution

Installed Xampp and start Apache and Mysql Services
Requires Python

After this simply open picrypt.html file it is very easy to use.
